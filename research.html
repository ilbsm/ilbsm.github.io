Projects & Software

All tools developed by the Sulkowska Lab are freely available online. Click any card to open the tool directly.

Protein Topology — Databases & Servers
AlphaFold
AlphaKnot 2.0
Database & webserver for entanglement analysis in AlphaFold-predicted protein models. Detects knots, slipknots and knotoids at proteome scale.
alphaknot.cent.uw.edu.pl →
AlphaFold
AlphaLasso
Server and database of proteins with lasso-type motifs found in AlphaFold models. Classifies loop and lasso topology in 3D biopolymer structures.
alphalasso.cent.uw.edu.pl →
KnotProt 2.0
Comprehensive database of proteins with knots, slipknots and knotoids from the PDB. The original reference resource for knotted protein structures.
knotprot.cent.uw.edu.pl →
LassoProt
Server and database of proteins with lasso motifs — covalent loops whose tail threads through the loop, classified by piercing number.
lassoprot.cent.uw.edu.pl →
LinkProt
Database of proteins with topological links — pairs of closed loops that are topologically entangled in protein structures.
linkprot.cent.uw.edu.pl →
Topology Identification — Plugins & Packages
Plugin
PyLasso
PyMOL/VMD plugin to detect lasso motifs in protein structures and analyze their geometric properties with 3D visualization.
pylasso.cent.uw.edu.pl →
Plugin
PyLink
PyMOL plugin to identify and visualize topological links in protein structures using link invariants.
pylink.cent.uw.edu.pl →
GitHub
Knot_pull
Python package for biopolymer smoothing and knot detection via iterative chain-pulling algorithm. Simplifies and classifies topology.
github.com/dzarmola/knot_pull →
Topoly
Package
Topoly
Python package for analyzing topology of polymers — computes knot and link invariants (Alexander, Jones, HOMFLY) for protein and polymer chains.
topoly.cent.uw.edu.pl →
Mechanical Properties
BSDB — Bio-molecule Stretching Database
Database of mechanical stretching of biomolecules. Force-extension data from coarse-grained simulations of proteins under mechanical force.
jowisz.ifpan.edu.pl/BSDB →
Structure Prediction — Co-evolution Methods
Server
DCA-mol
Plugin to analyze direct evolutionary couplings. Uses coevolutionary information from multiple sequence alignments for structure prediction.
dca-mol.cent.uw.edu.pl →
PconsFam
Database of Pfam protein families modelled using PconsFold2 — contact-assisted structure prediction for thousands of protein families.
pconsfam.bioinfo.se →
Server
GapRepairer
Server for automatic reconstruction of missing backbone fragments in protein models. Fills gaps in PDB structures using statistical methods.
gaprepairer.cent.uw.edu.pl →
Chromatin & Genome Topology
Server
KnotGenome
Server to detect entanglement in and between chromosomes. Identifies knots and links in chromatin fiber topology from polymer models.
knotgenom.cent.uw.edu.pl →
Biomolecular Complexity — Genus
Genus for Biomolecules
Database and server for genus characteristics of proteins and RNA chains. Uses minimal surface theory to quantify topological complexity.
genus.fuw.edu.pl →
